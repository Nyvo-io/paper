# π0 论文学习进度

> 本文件只是恢复学习会话的轻量断点，不是第二份学习笔记。正式内容统一保存在 [[Pi0 - A Vision-Language-Action Flow Model for General Robot Control]]。

## Covered

- π0 的输入：图像、语言指令与机器人本体状态。
- π0 的输出：未来一段连续动作组成的动作块。
- 动作块的两个收益：连续协调、摊薄 VLM 推理成本。
- 动作块的风险：后半段动作可能因环境变化或执行误差而过时。
- 缓解思路：执行短段后重新观察和规划。
- π0 的核心训练属于模仿学习/行为克隆，而不是以奖励为核心的强化学习。
- 条件流匹配从噪声构造插值状态，并学习通向示范动作的向量场。
- 推理时用 10 步 Euler 积分生成动作块；这些积分步不是机器人动作。
- VLM 主干处理图像和语言；动作专家处理机器人状态和带噪动作，并通过自注意力读取观察上下文。
- 三块式注意力让图像、语言和状态 KV 可在流匹配的多次前向计算中缓存，只有变化的动作块需要重算。
- 预训练强调跨任务、跨场景和跨机器人的多样覆盖；后训练强调目标任务上的一致、流畅执行。
- 仅有理想成功轨迹时，策略缺少偏差状态和恢复行为的覆盖，实际执行中容易遭遇分布偏移。
- 预训练按“任务-机器人”组合使用 $n^{0.43}$ 的次线性权重，减弱超大数据组合的支配效应。
- 跨机器人训练使用 $18$ 维状态/动作容器、零填充和缺失相机掩码统一接口；这不等于不同机器人的动作语义天然相同。
- 零填充解决跨平台张量接口兼容，不自动解决不同机器人的动作语义对齐。
- 后训练用任务专用数据将通用能力适配为流畅技能；论文给出的任务数据需求从约 $5$ 小时到 $100$ 小时以上不等。
- 后训练优先追求任务专用数据的一致性、流畅性和有效执行，而不是单纯追求成功轨迹数量。
- 高层 VLM 把总体任务分解为语言子任务；π0 再把当前语言子任务转换为连续动作块。
- 训练负责学习 π0 的参数；部署时的推理根据当前条件生成具体连续动作，而不是高层 VLM 直接输出关节数值。
